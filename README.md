# Programación para Entornos Web 1 — Universidad de Caldas (334G8F)

Sitio interactivo del curso: lecciones, inspectores tipo F12, demos en vivo, laboratorios con calificación automática y quizzes.

- **Sin build**: abre `index.html` o publícalo en GitHub Pages.
- **Disponibilidad**: `js/course.js` → `openUntil: '3.t'` habilita hasta el Módulo 3. Cambia el valor (o `null`) para abrir más temas.
- **Avance docente**: `Course.cur` y `Course.done` marcan "estamos aquí".

## Flujo de ramas
`develop` = trabajo diario · `main` = solo lo que se despliega (GitHub Pages).

## Herramientas de aula (rama `develop_mejoras`)
Botón flotante **Aula** (abajo a la derecha) y atajos de teclado: `B` menú · `F` pantalla completa · `M` modo enfoque · `+`/`−`/`0` tamaño · `L` láser · `D` pizarra · `T` temporizador · `K` buscar lección · `←`/`→` anterior/siguiente · `?` ayuda. El **modo docente** desbloquea todas las lecciones solo en el equipo donde se activa.
